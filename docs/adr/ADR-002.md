# ADR-002: Selection of CVXPY for Constrained Quadratic Programming (QP)

## Status
**Accepted**

## Date
2026-10-03

## Context
Autonomous portfolio rebalancing requires determining the optimal adjustment vector $\mathbf{w}_{\text{trade}} \in \mathbb{R}^n$ that minimizes portfolio tracking error variance relative to a target Strategic Asset Allocation (SAA) while adhering to strict real-world constraints:
1. **Objective Function**:
   $$\min_{\mathbf{w}_{\text{trade}}} (\mathbf{w}_{\text{curr}} + \mathbf{w}_{\text{trade}} - \mathbf{w}_{\text{targ}})^T \boldsymbol{\Sigma} (\mathbf{w}_{\text{curr}} + \mathbf{w}_{\text{trade}} - \mathbf{w}_{\text{targ}}) + \lambda \|\mathbf{w}_{\text{trade}}\|_1$$
2. **Hard Constraints**:
   - Budget conservation: $\mathbf{1}^T (\mathbf{w}_{\text{curr}} + \mathbf{w}_{\text{trade}}) = 1.0 + \Delta \text{cash}$
   - Long-only non-negativity: $\mathbf{w}_{\text{curr}} + \mathbf{w}_{\text{trade}} \ge \mathbf{0}$
   - Turnover budget: $\frac{1}{2} \|\mathbf{w}_{\text{trade}}\|_1 \le \tau_{\max}$
   - SEBI single-issuer limit: $w_i \le 0.10$
   - SEBI industry sector limit: $\sum_{i \in \text{Sector}} w_i \le 0.30$
   - Minimum liquidity cash buffer: $w_{\text{cash}} \ge 0.02$
   - Minimum trade lot threshold: $|w_{\text{trade}, i}| \ge \Delta w_{\min} \lor 0$

Heuristic search, genetic algorithms, and unconstrained mean-variance solvers either fail to guarantee constraint satisfaction or lack mathematical convergence guarantees.

## Decision
We selected **CVXPY** (version 1.4+) backed by conic/quadratic solvers (`OSQP`, `CLARABEL`, and fallback `SCS`):
- **Convex Formulation**: Discipline Convex Programming (DCP) rules guarantee global optimality with zero risk of local minima traps.
- **Two-Pass Mixed-Integer Thresholding**: To enforce minimum trade size without incurring NP-hard full MIQP execution latency, the solver executes continuous QP in Pass 1, identifies sub-threshold trade allocations ($|w_i| < \Delta w_{\min}$), clamps them to zero via parameter masks, and performs a rapid refinement solve in Pass 2 (<15ms).
- **Analytical Fallback Engine**: If CVXPY is unavailable in lightweight runtime environments, an analytical projection algorithm computes the nearest Euclidean point on the simplex while respecting the turnover budget.

## Consequences

### Positive
- **Guaranteed Feasibility**: Strictly enforces statutory SEBI caps and cash flow constraints.
- **High Throughput**: OSQP and CLARABEL solve typical 5–20 asset QP formulations in 8–25 milliseconds per portfolio.
- **Mathematical Transparency**: Yields exact dual variables (Lagrange multipliers) indicating which constraints are binding, feeding directly into advisor explainability dossiers.

### Negative / Trade-offs
- Requires native compilation of C-based solver libraries (`osqp`, `clarabel`, `scs`).
- Covariance matrix $\boldsymbol{\Sigma}$ must be strictly positive semi-definite; solved via eigenvalue clipping: $\boldsymbol{\Sigma} \leftarrow \frac{1}{2}(\boldsymbol{\Sigma} + \boldsymbol{\Sigma}^T) + \epsilon \mathbf{I}$.

## Alternatives Considered
1. **SciPy `optimize.minimize` (SLSQP)**: Evaluated, but found 4–8x slower than CVXPY with OSQP, prone to numerical gradient instability under non-smooth L1 turnover penalties.
2. **PyPortfolioOpt**: Built on top of CVXPY, but too rigid for custom SEBI sector constraints, tax penalties, and multi-pass lot thresholding.
3. **Commercial Solvers (Gurobi / MOSEK)**: Unnecessary licensing costs and deployment overhead for quadratic programs under 100 assets.
