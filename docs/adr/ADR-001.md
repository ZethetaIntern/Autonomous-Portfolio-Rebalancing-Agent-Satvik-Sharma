# ADR-001: Selection of CrewAI for Multi-Agent Hierarchical Orchestration

## Status
**Accepted**

## Date
2026-10-03

## Context
WealthPilot AI requires an autonomous, fault-tolerant orchestration architecture to manage complex portfolio rebalancing across 50,000 investor portfolios. The system must coordinate discrete, specialized quantitative domains:
1. Multi-factor trigger reception and dynamic priority queueing.
2. Constrained portfolio optimization and discrete order generation.
3. Indian capital gains tax minimization (Sections 111A/112A) and wash-sale compliance.
4. Pre- and post-trade Value-at-Risk (VaR), tracking error estimation, and stress testing.
5. Pre-trade SEBI regulatory compliance verification (Circular `SEBI/HO/MRD/DOP1/CIR/P/2024/69`).
6. Multi-audience explainability generation across Client, Advisor, and Compliance tiers.

Single-agent LLM systems or monolithic monolithic algorithmic pipelines lack domain separation, modular testability, and deterministic fallback controls. Conversely, raw LangChain chains lack built-in role specialization, delegation hierarchies, and standardized consensus protocols.

## Decision
We adopted **CrewAI** with a dual-execution pattern:
- **Hierarchical Specialist Agent Swarm**:
  - `OrchestratorAgent`: Central coordinator managing task prioritization, retries (max 3 with progressive constraint auto-tightening), escalation dispatch, and thread-safe shared state (`SharedMemoryStore`).
  - `PortfolioAnalystAgent`: Quantitative QP optimization and discrete trade ticket sizing.
  - `TaxSpecialistAgent`: Lot-level HIFO depletion, tax-loss harvesting, and wash-sale proxy rerouting.
  - `RiskManagerAgent`: Parametric VaR, tracking error, and stress testing.
  - `ComplianceOfficerAgent`: SEBI suitability, concentration caps, and cryptographic audit hashing.
  - `ExplanationWriterAgent`: Audience-tailored narrative synthesis with SHAP/LIME attributions.
- **Dual-Mode Execution Architecture**:
  Every agent provides both a deterministic, high-throughput Python API (`execute(...)` taking <50ms) and an optional CrewAI `Agent` object (`as_crewai_agent()`) for agentic collaboration and autonomous deliberation.

## Consequences

### Positive
- **Domain Decoupling**: Each specialist agent encapsulates distinct domain logic, data models, and validation rules.
- **Resilience**: Orchestrator retry loops dynamically relax non-statutory parameters upon solver failure before escalating to human advisors.
- **Auditability**: Shared memory maintains an immutable event log recording agent consensus, timestamped decisions, and intermediate artifacts.
- **Hybrid Performance**: Real-time batch workloads execute via vectorized deterministic methods, while complex exceptions leverage CrewAI agent reasoning.

### Negative / Trade-offs
- Additional library dependency (`crewai >= 0.28.0`).
- Monkey-patching required for Python 3.13 compatibility (`skip_file_prefixes` in warning hooks).

## Alternatives Considered
1. **LangGraph**: Evaluated for statechart graph execution, but rejected due to higher boilerplate for agent role specifications and less intuitive human-in-the-loop task handoffs.
2. **AutoGPT / BabyAGI**: Rejected due to non-deterministic looping, lack of financial constraint validation, and inability to meet sub-second SLAs.
3. **Monolithic Script Pipeline**: Rejected due to inability to support multi-stakeholder overrides, adaptive retry loops, and explanation generation across divergent personas.
